# Healther Brand Assets

## Logo meaning

- 中心圆点：妈妈本人；
- 内外两层路径：用药、就诊、报告和复查被持续整理；
- 薄荷色上扬段：完成今天的一件事，长期管理有清晰路径。

## Core colors

- Care Blue: `#6F8FDC`
- Mist Blue: `#8BB0F2`
- Calm Mint: `#72CDBD`
- Soft Canvas: `#F4F8FF`

## Files

- `healther-logo.svg`: 主品牌图标；
- `healther-logo-round.svg`: 圆形启动器版本；
- `healther-logo-foreground.svg`: Android Adaptive Icon 前景；
- `healther-logo-final.png`: 1024 × 1024 交付预览；
- `healther-logo-concept-a/b/c.png`: 早期方向探索。

图标应保持安全留白，不添加红十字、心电图、药丸或疾病名称，不改变中心圆点与双层路径的相对关系。Android Adaptive Icon 前景按画布的 72% 居中显示，避免 OPPO 等厂商蒙版裁切后视觉过满。
